# UCI Mushroom data

`agaricus-lepiota.data` is the Mushroom dataset from the UCI Machine Learning
Repository, downloaded from `https://archive.ics.uci.edu/static/public/73/mushroom.zip`.

Citation: *Mushroom* [Dataset]. (1981). UCI Machine Learning Repository.
https://doi.org/10.24432/C5959T

UCI distributes the dataset under CC BY 4.0. The original records describe
hypothetical Agaricus and Lepiota specimens from the Audubon Society Field Guide.
