# UCI Heart Disease Data

`processed.cleveland.data` is the processed Cleveland database from the UCI Heart
Disease dataset (dataset ID 45), created by Andras Janosi, William Steinbrunn,
Matthias Pfisterer, and Robert Detrano.

- Source: https://archive.ics.uci.edu/dataset/45/heart%2Bdisease
- DOI: https://doi.org/10.24432/C52P4X
- License: Creative Commons Attribution 4.0 International (CC BY 4.0)

The environment removes the six rows containing `?` and uses the remaining 297
complete records. Continuous observation thresholds were frozen from the separate
UCI Statlog Heart cohort before any Cleveland policy endpoint was evaluated.
