## Frozen Action Bank

There are exactly 32 single-experiment actions. A separate
`random.Random(24366)` instance constructs a Latin-hypercube design:

1. independently shuffle bins `0..31` for each of three dimensions;
2. draw one uniform jitter within each selected bin;
3. map adiabatic index linearly to `[1.3, 1.7]`;
4. map temperature log-uniformly to `[10, 1000]`; and
5. map molar mass log-uniformly to `[0.001, 0.1]`.

SHA-256 is:

No new action, local perturbation, endpoint, hand-selected diagnostic

## Exact Planning Audit

The prior is uniform and entropy is measured in nats. Gaussian likelihoods
are evaluated in log space and posterior probabilities are normalized with
log-sum-exp.

Expected entropies use deterministic Gauss-Hermite quadrature. The primary
calculation uses 15 nodes. A 9-node calculation is an independent numerical
convergence check using the same support and action bank.

For each action:

- immediate EIG is prior entropy minus expected one-step posterior entropy;
- depth-two EIG is prior entropy minus expected terminal entropy when the
  second action is selected adaptively, after each first observation, from the
  same 32-action bank; and
- reusing the first action at the second step is allowed, matching the
  benchmark's experiment interface.

The greedy root maximizes immediate EIG, then depth-two EIG, then frozen action
order. The non-myopic root maximizes depth-two EIG, then immediate EIG, then
frozen action order. Ties use a numerical tolerance of `1e-12`.

## Strict Opportunity And Gate

A noise stratum is a strict non-myopic opportunity only if all conditions hold:

1. greedy and non-myopic roots differ;
2. non-myopic immediate EIG is at least `0.01` nats lower;
3. non-myopic depth-two EIG is at least `0.01` nats higher than the greedy
   root followed by its own optimal observation-conditioned continuation;
4. both margins retain their signs under 9-node quadrature;
5. the 9-node and 15-node calculations select the same two roots; and
6. each reported immediate and depth-two value differs by at most `0.005` nats
   between the two quadrature orders.

The environment gate passes if at least one of the three declared strata is a
strict opportunity. All three remain in the result. A pass identifies a
predeclared environment setting with a real adaptive design gap; it is not
itself an LLM efficacy result.

A failed gate permits only a deterministic result write-up. It does not permit
an OpenRouter call, threshold repair, support restriction, action-bank edit,
noise interpolation, or same-module retry. A passing stratum may be selected
for a later smoke only in a fresh preregistration written before any model
response.

## Conditional LLM-Native Smoke

Only a full gate pass may authorize a later development smoke. The intended
mechanism is:

- the LLM generates semantic candidate laws and probabilities from the task
  and realized experiment history;
- the LLM predicts hypothesis-conditioned likelihoods or qualitative outcome
  branches for candidate experiments;
- the LLM regenerates path-dependent beliefs after simulated outcomes; and
- exact code compares myopic and depth-two choices on the same generated tree.

The released nine-law registry is an oracle diagnostic only and must not
become the headline policy's fixed hypothesis support. Reasoning is reserved
for a naive thinking baseline, not required for the BED policy. Any model
smoke must preserve the `$25` OpenRouter reserve, fit within the separate
through-Monday operating cap, and use no OatML resources.
