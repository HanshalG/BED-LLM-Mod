New physics_edits.py preserves a supplied executable base and asks only for a
correction tree. Composition is base+correction or base*correction. The correction
uses the existing bounded arithmetic language, not a finite registry of known
mechanisms. AST composition preserves grouping and safe execution; strict schema,
whole-response validation and syntax dedup remain. There is no direct reference to
hidden source structures, task labels or target outcomes. The language is still
bounded and restricted; its combinatorial size does not itself prove LLM necessity.

The numerical updater remains responsible for positive response/domain checks,
full-history likelihood, global-scale integration, weights and predictions. A
negative correction can be valid when the composed response stays positive.
Constant factors are not silently discarded: they may be an unhelpful model output
and global calibration can already absorb scale. No heuristic repairs or source-
dependent shortcuts. Existing parameterization-dependent scale-prior caveat remains.
