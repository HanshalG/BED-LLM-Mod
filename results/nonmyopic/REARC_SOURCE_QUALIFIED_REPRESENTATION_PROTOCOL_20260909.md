# Prospective source-qualified representation study

This is a new sampling protocol, not a retry of the closed representation cohort.
Keep the shared-plan Python-vsDSL controller, Luna medium, 30-call/$2.40 maximum,
16 slots per arm, predictive formulas and all qualification gates in
REARC_REPRESENTATION_PROTOCOL_20260909.md. No depth efficacy is authorized.

Before source execution, freeze 24 candidate IDs by first24 ascending
SHA256(`bed-rearc-source-qualified-v1:` + ID), excluding all 50 IDs in the union
of the preceding representation manifest's excluded and selected IDs. Use
demonstration seed48100, query seeds48200..48201 and target seeds48300..48307.
The later controller's model seeds remain46400+3*i+[0,1,2], where i is retained
task order. No task-body or model-performance selection is permitted.

Process candidate tasks in order. Each exact 11-channel schedule is journaled
once. Accept only tasks whose entire schedule passes grid validation and
generator/reference verification. A sanitized worker verify-phase ValueError
rejects that task and permits advancing to the next frozen candidate. It may
mean a reference exception, invalid reference grid, or output mismatch; do not
misreport all such failures as output disagreements. All other failures,
including timeout, malformed transport and generation failures, abort the pool.
Do not retry any request or change seeds. Stop immediately after six accepted
tasks, or fail on exhaustion of24. Maximum264 source attempts, zero API calls.

This is prospective reference-consistency screening, not model-informed task
replacement. All attempted IDs and source rejections must be reported. Inference
is explicitly restricted to this fixed-schedule reference-valid population;
do not claim performance across the full RE-ARC inventory. Unattempted candidate
IDs remain reserved to this protocol, not available for opportunistic selection.
Already closed cohorts remain closed. No verification threshold is weakened.

Only demonstration outputs are public. Every retained query/target output is
represented by its hash until complete predictions are sealed and the observed
coverage gate passes. A qualified source pool alone permits no paid call:
actual prompt preflight, immutable source/interface bindings, budget dispatch,
raw-response banking and exact terminal/failure replay must be connected first.
Subsequent predictive failure closes the entire retained cohort; it cannot be
replaced using additional valid tasks from this pool.

This source screen solves a data-integrity dependency only. It does not establish
model calibration, planning opportunity, monotonic depth benefit or publication
readiness. Those require the separate sequential tests already stated in the
representation protocol.
