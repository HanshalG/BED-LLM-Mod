# Cross-generation initial-belief transport diagnostic

Retrospective, zero-call diagnosis; does not reopen the initial_opportunity_null
gate or its >=5% condition. Only the exact INITIAL_ONLY projection00109f27 is
read; no future proposals, original TREES object, or historical target bank.

For each of32saved supports, deploy the original exact h1/h2/h3 rule for three
queries. Worlds are unique initial extensions from each OTHER support, uniformly
weighted within donor, with equal weight per donor. Repeated extensions across
donors retain donor multiplicity. Uniform prior within the recipient is unchanged.
Smallest-query exact tie breaking remains; if resolved early, fill with smallest
unused query. This filler is explicitly specified for the new diagnostic since
out-of-support answers can falsify a resolved belief. Never reset an empty
posterior, mix an emergency prior or silently omit a failed world.

Report exact-extension coverage, impossible-answer probability at each depth,
and unconditional Brier interval: sum of successful-world weighted losses as
lower bound, plus failure mass as upper bound (loss in[0,1]). Successful-world
conditional loss is diagnostic only, not a fair policy comparison when coverage
differs. Do not claim an unconditional depth advantage unless separated bounds
support it. Retain all32recipients and all donor extensions; no seed/subset
selection. Existing30s/250000state per-solver limits remain.

This evaluates transport across LLM initial generations, not calibration to
independent human concepts, a physical source, or a population sample. Donors are
shared and correlated, so no naive independent-world confidence interval. It
cannot authorize a paid study, lower the old gate, or establish the main result.
Numerical regression must reproduce original in-support policy risk before run.
