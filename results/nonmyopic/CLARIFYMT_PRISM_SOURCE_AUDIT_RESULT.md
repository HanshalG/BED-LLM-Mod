# ClarifyMT-Bench And Prism Source Audit Result

## Decision

Neither released interface currently qualifies as the experimental substrate for
the project's LLM-native non-myopic BED claim. ClarifyMT-Bench is closed as a
fixed-transcript clarification classifier. Prism is retained as related-method
motivation for answer-conditioned question generation, but its advertised source
repository is currently unavailable and the paper's released formulation does not
define a Bayesian latent-world evaluation.

No OpenRouter calls were made.

## ClarifyMT-Bench

- Official repository: `https://github.com/sichunluo/ClarifyMT-Bench`
- Audited commit: `f4417c89f4940d674faa4546d6d9a1d4fcf5c7cc`
- Released data SHA-256:
  `693a34db95e2170b817af72ad0fce7f5e3ca243508408f87386710a8b510a1dc`
- Rows: 6,120
- Base ambiguous prompts: 1,020
- Personas per prompt: six
- Conversation lengths: 2,040 three-message rows and 4,080 six-message rows

Every base prompt is crossed with exactly the six fixed personas: Precise,
Partial-Vague, Off-Focus, Contradictory, Factually-Wrong, and Refusal. The
released inference runner truncates each row to its first three messages and asks
the evaluated model only whether to clarify or answer. The evaluator then checks
that string against a persona-level rule.

This release contains no alternative intent particles for one prompt, no
question-conditioned response function for a newly selected clarification, no
counterfactual branches, and no endpoint over a recovered hidden intent. Its
multi-turn records are generated transcripts, not an environment that can answer
an intervention chosen by our policy.

## Prism

- Paper: `https://arxiv.org/abs/2601.08653`
- Advertised repository: `https://github.com/liaozenghua/Prism`
- Repository status at audit time: HTTP 404 / Git clone unavailable

Prism is mechanistically useful literature. It represents 429 complex intents as
human-validated prerequisite graphs, generates later clarification tables from
earlier user answers, and uses forward conversation sampling to score complete
trajectories. This directly supports the project's premise that useful
clarification actions can be answer-conditioned.

It is not yet a usable BED benchmark for this project:

- the prerequisite graph prescribes a topological clarification order;
- the paper does not expose competing latent worlds with a prior;
- its reward combines token importance and generation confidence rather than
  posterior uncertainty or exact latent-intent utility;
- the user and future trajectories are generated by the policy-side LLM;
- the unavailable repository prevents a source-level audit of CID records,
  simulator prompts, held-out splits, and counterfactual replay.

## Consequence

Do not spend the protected OpenRouter allowance on either source. Cite Prism as
evidence for semantic dependency-aware clarification if useful, and retry its
repository later. A future Prism-derived experiment would first need an accessible
frozen CID split, explicit alternative intent worlds, a question-to-response model
under every world, and an independently scored endpoint.

OpenRouter calls/cost: `0 / $0`. OatML jobs: `0`.
