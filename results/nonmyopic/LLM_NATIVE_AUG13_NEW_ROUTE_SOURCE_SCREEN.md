# LLM-native new-route source screen

Date: 2026-08-13

Model calls/cost: **0 / $0**

## Decision

Select AgentClinic NEJM Extended for a source-first dynamic-support mechanics
audit. This does not authorize a model call or imply a non-myopic opportunity.

| Candidate | Released evidence | Decision |
|---|---|---|
| InfoSeeker | Eleven 50-case simulator variants; hidden dynamics are a few explicit booleans or fixed shifts/swaps and observations are deterministic templates | Reject for this claim: a classical planner can enumerate support and likelihoods exactly |
| ExCyTIn-Bench | Rich SQL investigation interface and semantic attack graphs, but only eight underlying incidents with many sibling path questions sharing each graph/database | Park: semantic work is real, but the effective independent population is too small for the primary claim |
| Cyber Defense Benchmark | Strong SQL threat-hunting formulation over real telemetry | Park: only one sample environment is publicly released; full benchmark requires access by request |
| Sequential Diagnosis Benchmark | 304 native question/test encounters reported | Watch only: benchmark cases and gatekeeper implementation are not publicly released |
| MediQ | 1,272 released cases and an executable patient simulator | Closed by existing registered project evidence: sparse answer availability and truth-harming likelihood calibration |
| AgentClinic NEJM Extended | 120 unique released NEJM cases; separate patient, test-reader, image, and diagnosis interfaces | Select for value-blind source partition and six-case mechanics gate |

## Why AgentClinic is only a candidate

AgentClinic makes the LLM role potentially irreducible: it must create a medical
differential and predict free-text patient/test responses from long clinical
records. It also exposes distinct history and investigation channels. However,
the native benchmark allows arbitrary questions and tests, so depth two may have
no structural advantage. The next mechanics gate must establish a changed root,
positive first-link value, calibrated counterfactual responses, and branch-induced
truth-support change before any opportunity or endpoint run.

The source screen opened no selected AgentClinic case content or endpoint. The
source audit subsequently bound the 120-row population and a hash-only split.
