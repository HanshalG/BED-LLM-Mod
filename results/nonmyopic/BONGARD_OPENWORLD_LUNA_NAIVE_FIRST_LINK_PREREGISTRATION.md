# Bongard OpenWorld Luna Naive First-Link Preregistration

Date frozen: 2026-08-07, before any naive-baseline model response and before
any Bongard scientific endpoint is opened.

The prospective development-64 power amendment frozen on 2026-08-08, before
any Bongard planner response or endpoint access, doubles only the development
choice cohort and scales the count gates proportionally. The already passed
ten-call mechanics smoke, model, prompt, policies, effect thresholds, dates,
and endpoint boundary remain unchanged.

## Question

Does formal non-myopic BED choose a better first query than a direct
medium-reasoning VLM when both policies receive the same initial labelled
examples and the same selectable images?

This is a baseline, not part of the LLM belief generator. All belief-generation
calls in the main experiment remain nonreasoning. The baseline asks GPT-5.6
Luna to choose one first query directly. After the realized first label, it
uses the main dynamic policy's regenerated branch belief and second-step EIG.
This common continuation isolates the first-link decision and maps every
choice to a terminal belief already generated by the main all-first-action
cache.

## Information Boundary

Each baseline prompt contains:

- the four initially labelled images and their labels;
- the eight selectable unlabelled candidate images; and
- opaque image IDs in a seed-shuffled display order.

The two held-out endpoint images and all candidate/endpoint labels are absent.
The model receives no generated hypotheses, EIG scores, branch beliefs,
source concept, dataset paths, or policy choices. It returns exactly
`{"first_image_id": "..."}` under a strict schema. The selected ID must be one
of the eight candidates.

## Model And Calls

- Model: `openai/gpt-5.6-luna` through OpenRouter.
- Reasoning effort: `medium`; reasoning content excluded from the response.
- Maximum completion: 8,192 tokens.
- Temperature: provider default after unsupported sampling fields are removed.
- Maximum reserved cost per attempt: `$0.008`.
- Only the frozen bounded same-payload transport retries may pass; semantic
  reissues and forced-final continuations remain forbidden.

An exact ten-call mechanics-only serving smoke must pass before development.
The smoke uses only the four permanently open mechanics tasks and accesses no
candidate or endpoint label. Development uses one call for each of the 64
frozen tasks, 16 per block on August 11--14, after that day's main block has
completed. Each baseline block has a `$0.20` cap, so the main `$4.75` cap plus
the baseline cap fits the account-wide `$5.00` daily ceiling.

## Frozen Evaluation

The four endpoint-blind choice blocks are independently replayed. Only after
the main four-block combined result has opened its endpoint does the baseline
analysis join each selected first ID to
`all_first_action_paths[first_image_id]`. Therefore the first label, dynamic
second query, terminal history, terminal belief, and endpoint scorer are
exactly the main cached realization for that first action.

Report paired dynamic-minus-naive and myopic-minus-naive differences for
terminal mean Brier and log loss, with 20,000 task bootstraps using seed
`2026080751`. Report first-action agreement and final-history agreement.

A separately labelled `dynamic_beats_naive_thinking` development signal
requires all of:

1. exact 64 unique task choices and clean replay;
2. at least 16 dynamic-versus-naive final-history differences;
3. at least 3% lower mean Brier for dynamic than naive;
4. bootstrap probability at least 0.80 that dynamic Brier is lower; and
5. dynamic mean log loss no worse than naive.

This signal cannot rescue, alter, or authorize the main development result or
confirmation. A null remains reportable as a baseline result. No criterion is
changed after responses or endpoint access.

## Scope

The baseline tests whether explicit BED adds value over direct VLM reasoning
at the first decision. It does not compare complete independent two-query
policies because the shared dynamic continuation is intentional: it removes
second-step updater quality as a confound and matches the project's first-link
causal claim.
