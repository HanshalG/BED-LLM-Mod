# Post-Tau2 LLM-Native Source Admission Audit

Date: 2026-08-13

Status: **zero-call portfolio decision; no paid experiment authorized**.

## Decision

The project already has two substantive LLM-native results. Number Game is the
robust policy headline: powered non-myopic selection and disjoint matched
history-blind conditioning tests are positive, while the fully fresh causal
mechanism remains qualified. tau-Knowledge is a genuine external-endpoint
result: its first held-out 20-task execution passed every frozen root,
continuation, and endpoint gate, but a clean same-task full regeneration
reversed root ranking and tied myopic document coverage.

The next useful result is therefore a new-task or new-environment replication,
not another execution of exhausted tau-Knowledge tasks and not another prompt
repair on a closed source.

## Next Admission Contract

Before a paid policy call, require: an immutable released population; forkable
hidden states; unrestricted semantic actions; answer-obedience and repeated-fork
stability; a source-verifiable first-action horizon opportunity that survives a
compute-matched receding myopic control; a target-blind nonsaturated endpoint;
sealed development and confirmation outcomes; dynamic, fixed, myopic, and
random controls; paired common-random-number evaluation; and a low-cost
fail-closed runner.

Dialogue SWE-Bench is the highest-priority watch candidate if its authors
publish the promised code and task data. Ambig-SWE should be reconsidered only
after an upstream aligned release under a new source protocol. New searches
should prefer native prerequisites or gated sensors, because additive missing
facts usually make greedy replanning sufficient.
