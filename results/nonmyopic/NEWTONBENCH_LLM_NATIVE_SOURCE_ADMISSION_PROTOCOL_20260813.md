# NewtonBench LLM-Native Source Admission Protocol

Date frozen: 2026-08-13, before executing any task, opening any saved trajectory,
or evaluating any target law.

## Objective

Determine whether NewtonBench can support non-myopic sequential BED in which an LLM
irreducibly generates an open, path-dependent scientific-law support or likelihood,
rather than approximating a finite benchmark-owned registry.

This is source admission only. A pass authorizes a separately frozen zero-call
horizon-opportunity screen. It authorizes no model response, target evaluation, or
paper efficacy claim.

## Immutable Source

- official repository: `https://github.com/HKUST-KnowComp/NewtonBench`;
- commit: `912a4ba5f4356ddd06acc16e44460ca30be4abc2`;
- Git tree: `88b68ea14e1ee6bc17a237642ab9eccde52faa48`;
- license: MIT.

The audit may inspect README, module names, law registries, physics/action interfaces,
prompts, and evaluator source. It may not run a task, invoke a hidden law, read saved
model trajectories/results, submit a candidate law, or open an evaluation outcome.

## Frozen Gates

All gates must pass in order:

1. **Bindings and population:** exact commit/tree/license and the declared 324-task,
   12-domain population are present.
2. **Native sequential experiment:** the policy can select experiments, receive
   deterministic or explicitly noisy observations, and submit a machine-evaluable
   law.
3. **Finite-budget horizon:** the native task must constrain experimental batches or
   measurements so that an enabling first experiment can improve the value of a later
   experiment. An arbitrary-size noiseless batch in one action fails this gate.
4. **Open-support ownership:** the source must not publish a complete finite registry
   of every target law in the evaluated population. A registry indexed by domain,
   difficulty, and version fails even when the prompt hides the selected entry.
5. **Irreducible LLM role:** the intended LLM support/likelihood cannot be replaced by
   enumerating source-owned laws and executing the released simulator.
6. **Exact controls:** the source admits paired depth-two, compute-matched myopic,
   exhaustive-registry, and random controls under common task and observation noise.
7. **No privileged publication:** the result contains only hashes, aggregate counts,
   interface booleans, and gate outcomes. It contains no law equation, constant,
   selected task/version, observation, prediction, or model output.

The audit stops at the first failure. Later gates remain not evaluated.

## Decision

- `source_pass`: authorize only a fresh zero-call mechanics screen establishing a
  changed first experiment and positive terminal law-recovery gain.
- otherwise: close the exact NewtonBench release as an LLM-native non-myopic headline
  route. It may remain a scientific-reasoning benchmark or classical/hybrid baseline.

No post hoc action limit, hidden-law subset, or omission of the released registry may
convert a failure into a pass. A materially different upstream release requires a new
prospective protocol.
