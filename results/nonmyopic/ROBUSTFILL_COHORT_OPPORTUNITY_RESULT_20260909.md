## Limits and decision

This is exact planning under256-draw empirical laws, not exact full-prior inference,
real held-out Brier, semantic calibration, or an LLM experiment. Shared input families
mean these twelve tasks are not twelve independent semantic families. The sampled
syntax prior may omit rare decision-relevant programs. No confidence interval or
population equivalence claim follows. Yet the complete screen is a stronger reason
not to pay for a depth sweep than the preceding two-task check.

Do not tune seeds, shorten acquisition budget, choose a favorable subset, or change
prior after this null and claim the same prospective test succeeded. Bank this
finite-string configuration as a poor current depth candidate. Its representational
fix worked, but it did not establish either a useful planning gap or LLM necessity.

Next research decision must return to the central mechanism: queries whose answers
change which useful semantic mechanisms the LLM can propose, and a calibrated joint
simulator of those changes. A broad literature/source comparison should prioritize
measured discovery/enabling structure over another easy-to-enumerate syntax task.
Any new environment/interface must declare its own evaluation and include ordinary
myopic and matched-compute controls. This null does not justify spending merely
because daily allowance remains, nor abandoning the original LLM-native objective.
