# ChemBench Speculative-Particle Mechanics V3 Protocol

Date frozen: 2026-08-14 (Europe/London)

V3 is a prospective successor to the verified V2 null. It changes the planning
belief identified by that terminal first-link diagnostic; it does not alter the
live-support proposal transition to fit the failed endpoint.

## Scientific Correction

V2 represented all absent model structures by one scalar unknown-support mass
with a uniform categorical predictive. That alarm could trigger support
expansion, but it supplied no structure-specific assay likelihood or held-out
forecast. Consequently the planner's leaf Bayes risk was not expected terminal
truth loss under its own model-generation process.

V3 carries two coupled beliefs:

```text
InferenceBelief:
  live + reserve executable structures, evidence weights, scalar outside alarm

PlanningBelief:
  weighted speculative executable world particles
```

The inference belief remains the source of the submitted forecast. The planning
belief defines predictive branch probabilities and evaluates that forecast
against possible endpoint functions. After a simulated observation, the
planning particles receive an exact Bayesian weight update while the inference
belief undergoes the same cached proposal, evidence, live/reserve, and unknown
update as V2.

## Oracle Ceiling

For zero-call mechanics only, the speculative set is the complete 48-world
outside-support cohort with uniform initial weight. This reveals no selected
truth identifier; it is a prior over every eligible truth and remains separate
from the live inference support. It is a non-deployable calibration ceiling.

The future LLM route must replace this set with LLM-proposed executable
structures. Its semantic gate must therefore measure speculative support
coverage, predictive calibration, and action-ranking fidelity before efficacy.

## Leaf Objective

For speculative state `(B, q)`, let `f_B` be the represented live/reserve Bayes
forecast on the 1,000 public proxy assays and let each speculative particle `j`
have target function `f_j`. The leaf value is

```text
sum_j q_j * mean_proxy((f_B - f_j)^2)
```

Do not add entropy, symbolic-identity reward, truth posterior reward, or the
scalar unknown penalty. Planning branch probability is
`sum_j q_j p(outcome | model_j, action)`. The selected real truth appears only
in evaluator replay, never in policy state, proposal cache, or action scoring.

This construction must satisfy a synthetic calibration identity: at any frozen
state and action, the planned expected leaf value equals prior-weighted
truth-conditional replay to numerical tolerance.

## Call-Matched Control

Run speculative d3 first, then d2 and d1 through one immutable registry-oracle
proposal cache. Recreate speculative d1 with empty planner memoization and the
same cache; it must add zero producer misses and exactly reproduce d1. The
call-matched control receives the complete cached proposal work but scores only
one future speculative transition.

## V3 Conjunctive Gate

1. Source/version/privacy/finite/normalization and zero-call checks pass.
2. Synthetic and source replay identities between planned leaf value and
   truth-conditional expected loss pass within `1e-10`.
3. Call-matched d1 replay is exact with zero new proposal misses.
4. d2 aggregate terminal MSE is at least 5% below d1.
5. d3 aggregate terminal MSE is at least 5% below d2.
6. Each successive comparison wins more paired truth cells than it loses.
7. d2 changes the d1 root on at least one of three slices.
8. Root candidate predicted value has positive Spearman correlation with
   forced-root realized terminal risk on every slice for d2 and d3.
9. Aggregate d2 and d3 top-1 regret are each below d1 top-1 regret.
10. Fixed and history-blind controls never consume registry-oracle proposals.
11. Independent replay exactly reproduces transition bank, roots, per-truth
    losses, ranking diagnostics, and gate.

The scalar V2 planner and scripted proposer are descriptive and cannot rescue a
failed speculative gate.
