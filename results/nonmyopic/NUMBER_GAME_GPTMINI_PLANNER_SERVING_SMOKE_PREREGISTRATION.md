## Purpose

This is a transport and structured-support gate for one prospective fresh
external-canonical Number Game confirmation. It cannot inspect or authorize
on efficacy.

## Frozen Design

- Model: `openai/gpt-5.4-mini`, non-reasoning, temperature `0.7`.
- Exactly ten accepted calls under request seed `53000`.
- Prompt mix: two prior supports, four one-observation histories, and four
  two-observation histories.
- Raw responses are checkpointed before parsing.
- Structured proposals use the same fixed `0..100` extension schema as the
  planned formal study.
- Hard run cap: `$0.10`; projected cost approximately `$0.03`.

The smoke passes only with exactly ten parsed responses, accepted requests,
and HTTP attempts; zero retries, provider-error retries, reasoning tokens,
and forced exits; at least 16 valid unique rules in both prior supports; at
least eight in every conditioned support; and spend at or below the cap.

Failure closes this serving attempt. No efficacy endpoint, planning score, or
policy comparison is computed here.
