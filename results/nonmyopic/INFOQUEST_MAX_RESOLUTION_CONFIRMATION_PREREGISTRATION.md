## Procedure

All model calls are temperature zero and non-reasoning.

1. One `openai/gpt-5.4` call per record generates eight latent scenarios and
   five distinct atomic clarification roots from the ambiguous request.
2. `google/gemini-2.5-flash` answers every root under each exact released
   hidden-world system prompt: 50 root answers.
3. One `openai/gpt-5.4` call per root/world history generates five atomic
   unresolved information needs, importance weights, and four action-resolution
   probability profiles using the already frozen compact V2 schema: 50 beliefs.
4. Only after all 50 compiler responses are privately checkpointed,
   `openai/gpt-5.4-mini` independently marks the five official immediate
   checklist bits for all root answers: ten judgments.

The root/need compiler never receives hidden settings, worlds, truth packets,
constraints, solutions, checklists, target labels, prior outputs, or metrics.
There are no follow-up simulator calls. Every batch is checkpointed before
parsing; repair, reissue, padding, inference, and dropped cells are forbidden.

## Frozen Scores and Controls

For action \(q\), the prospective method is:

\[
S_{\max}(q)=\max_i r_{qi}.
\]

The exact `A-D` argmax uses action order as the tie break. This rule was chosen
from the disclosed post hoc audit and is frozen before fresh content.

Paired controls use the same belief response, roots, histories, and target
labels:

- V2 linear expected resolved mass
  \(\sum_i w_i r_{qi}/(100\sum_i w_i)\);
- random action from `random.Random(24418)`;
- the target oracle, reported only as an opportunity ceiling.

Target gain is the previously validated additive proxy: candidate immediate
checklist bits not already supplied by the current root.
