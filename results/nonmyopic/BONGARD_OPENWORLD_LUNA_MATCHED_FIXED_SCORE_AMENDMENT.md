# Bongard Matched Fixed-Score Control Amendment

Date frozen: 2026-08-07, before any Bongard model response or scientific
endpoint.

## Confound

The existing `dynamic_depth2` versus `fixed_depth2` comparison changes both
the first-action score and the realized second-action updater. Dynamic depth
two chooses its second query from the answer-conditioned regenerated branch;
fixed depth two chooses it from an analytical update of the root support.

That is a fair comparison of complete policies, but it cannot by itself show
that anticipating path-dependent support improved the first query. A dynamic
win could instead be caused only by using the regenerated support after the
first real answer.

## Matched Control

Add `fixed_score_dynamic_update`:

1. Select the first query with the existing fixed-support depth-two score.
2. Observe the real first label.
3. Select the second query greedily from the same answer-conditioned
   regenerated branch used by `dynamic_depth2`.
4. Evaluate the same independently regenerated terminal belief.

Thus `dynamic_depth2` and `fixed_score_dynamic_update` have the same query
budget, branch generator, realized second-stage updater, terminal generator,
requested terminal seed, dispatch batch, and endpoint. They differ only in the
first-query score: path-dependent versus fixed-support lookahead.

Every possible first action's regenerated-branch continuation and terminal
history is already generated by the all-first-action ranking audit. The new
control therefore adds no model request, prompt, response, label access, seed,
batch, cost, or maximum exposure.

## Frozen Interpretation

The strongest path-dependent development tier must satisfy the existing
fixed-policy requirements and also beat the matched control: at least 12
different final histories and non-tied first actions, a difference in every
block, at least 3% relative Brier improvement, paired bootstrap probability of
improvement at least `0.80`, and non-worse log loss. Confirmation requires the
corresponding 24-history/action thresholds, every-block differences, at least
3% relative Brier improvement, paired tree-bootstrap 95% upper bound below
zero, and non-worse log loss.

The dynamic score must remain non-worse than the fixed score in the existing
common dynamic-continuation ranking audit. This ranking comparison now has the
same continuation semantics as the matched endpoint comparison.

Passing only the unmatched complete-policy comparison is non-authorizing and
cannot support a claim that path-dependent lookahead improved first-query
selection.

This amendment changes no task, image, belief prompt, response schema,
hypothesis count, branch weight, model, date, budget, endpoint, or original
policy-family threshold.
