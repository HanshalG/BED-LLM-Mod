## Shared-Action Paired Procedure

GPT-5.4 first generates K8 latent contexts and five atomic roots for each
ambiguous seed. For every root in both worlds, the other four roots, in their
original order, become the shared candidate bank `A/B/C/D`.

After the same simulator answers the first root:

1. the dynamic branch regenerates K8 support and emits one exact choice code;
2. the fixed branch copies the original K8 support verbatim and emits one exact
   choice code;
3. both JSON objects have exactly `h1..h8` and `choice`, under the same token
   cap;
4. the same simulator answers each selected candidate from matched histories;
5. one independent judge scores immediate, dynamic-two-turn, and
   fixed-two-turn official checklist discovery.

Neither branch may generate, rewrite, or score candidate actions. The parser
accepts only exact uppercase `A`, `B`, `C`, or `D`; the chosen action must be
one of the same four supplied roots. The fixed parser also requires exact,
ordered hypothesis copying.

All batches are checkpointed before parsing. No response is repaired, reissued,
deduplicated, imputed, or silently dropped.
