# Bongard Luna Naive Smoke Replay Amendment

Frozen: 2026-08-08, after the ten-request naive serving smoke and before any
development response or development scientific endpoint.

## Problem

The banked Luna medium-reasoning smoke passed its frozen serving contract under
`bongard-openworld-luna-naive-first-link-1`. The later endpoint-predictive
utility amendment advanced the naive implementation to interface 2 and bound
Development64 manifest V14. It did not alter the naive prompt, images, task
order, request seeds, display orders, response schema, model, reasoning effort,
or choice parser. The current verifier nevertheless rejects the banked result
at its old interface header before replaying those unchanged requests. Left
unrepaired, every same-day naive development block would fail before a model
call even though its required serving smoke already passed.

Repeating the same ten paid calls would add cost and model nondeterminism without
testing a changed interface. Relabelling the old JSON in place would destroy the
historical record. Neither is allowed.

## Frozen Repair

The original files remain byte-identical:

- smoke result SHA-256
  `f1070b30ea63f571ffac2e23f7b9cfb5fc97ad42dd95e0e6babefbc7ca387a70`;
- private raw-response SHA-256
  `281b9159ca3cd9e86f9d972e3da4fbaef0af4ecc0c1a3977f9723eef33e2c747`.

A zero-call replay certificate must independently reconstruct the current ten
sealed mechanics cases and current multimodal messages, then require exact
equality of every case ID, task ID, seed, display order, message SHA-256,
response count, strict parsed choice, and current prompt-privacy audit. It also
requires both candidate- and endpoint-label access flags to remain false, the
old result and raw hashes above, a clean original gate set, Luna medium
reasoning, and the original measured usage/cost record.

Only the exact banked path and hashes above may use this compatibility route.
Synthetic or future interface-1 results, changed old files, changed current
messages, changed choices, or a changed certificate fail closed. Native
interface-2 smoke results retain their existing verification path.

## Scope

- This authorizes no model request and costs zero dollars.
- It opens no candidate, endpoint, development, confirmation, or reserve label.
- It changes no formal development prompt, seed, task, policy, endpoint,
  threshold, request maximum, retry rule, or budget.
- It does not reinterpret the smoke as scientific evidence; the smoke remains
  a serving/schema/reasoning gate only.
- Development and confirmation manifests remain byte-identical. Only the
  descriptive naive-baseline manifest advances to bind this replay repair.
