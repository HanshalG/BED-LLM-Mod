Frozen before any Qwen response to the focused-prior h5 target-compiler

## Motivation And Scope

Gemma-4-26B-A4B passed one initial and three fresh hierarchical h5 trajectory
seeds. The strongest remaining limitation is model-family generality. This gate
changes only the semantic target compiler to dense `qwen/qwen3-14b` with
thinking enabled.

The prior Qwen h4 free-action interface is closed and remains negative: Qwen
occasionally composed the critical route but could not reliably serialize all
four action tails. This new test is not a rerun or rescue of those seeds. It
tests whether the already validated hierarchical decomposition transfers when
Qwen emits four semantic rock targets and deterministic code handles routing.
