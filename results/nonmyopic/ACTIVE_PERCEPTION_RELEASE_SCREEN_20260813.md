# Active-Perception Release Screen

Date: 2026-08-13

Status: **HiddenBench selected for source admission; ESI-Bench is infrastructure
blocked and ActiView lacks a demonstrated non-myopic structural gap.**

No model call, paid endpoint, or OATML cluster was used.

## ESI-Bench

The official release at commit
`3c1756396f32b1a90c1f72356a7fde45f418e179` is scientifically attractive:
3,502 leaf task records span 29 active spatial tasks, and the runner exposes
camera, locomotion, and manipulation actions against hidden physical state.

It is not currently executable in this project. The release contains task JSONs,
camera poses, and image filenames but only two repository PNGs; observations must
be rendered in OmniGibson with BEHAVIOR-1K assets. The authors explicitly warn
that the simulator renders poorly on Blackwell/50-series hardware and document
20/30/40-series GPUs. Without the released observation images or a compatible
graphics venue, a paired depth-two endpoint would not be reproducible here.

Decision: keep as a high-value watch route. Do not reconstruct or substitute
images, and do not use OATML under the current instruction.

## ActiView

The official release at commit
`af2ec5687cb81d57cb3f994f7d74af5147c431e5` has 325 multiple-choice visual
questions and a downloadable 715 MB image archive. Each image has four selectable
crops, making the environment locally executable.

Its published mixed pipeline presents the full low-resolution image at the root,
then permits any subset of the four independent crops. The second operation may
keep or exchange crops, but no action unlocks another action and every crop is
available immediately. The release therefore establishes active perception, not
the immediate-information sacrifice required for a non-myopic BED first-link
claim. A deeper planner would mostly select a crop set under a budget.

Decision: do not spend on this route unless a prospective zero-call construction
first proves a changed depth-two root against a compute-matched myopic selector.

## HiddenBench

HiddenBench was selected because its release supplies an immutable semantic
hidden world and a sequential private-information channel, while withholding the
counterfactual option-conditioned worlds and likelihoods. That missing structure
must be generated by the LLM and can be tested before any policy endpoint. The
separate source protocol and result bind the exact population and next gate.
