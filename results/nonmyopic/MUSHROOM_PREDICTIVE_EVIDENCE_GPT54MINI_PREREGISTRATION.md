# UCI Mushroom Predictive-Evidence GPT-5.4 Mini Preregistration

Status: frozen after implementation and deterministic tests, before any model response
under this treatment.

## Question

The confirmed utility-grounded treatment gives every branch the exact expected class
entropy and one-step information gain of each legal continuation. It therefore proves
that a machine-grounded LLM-Modulo interface can assemble and serve a depth-two policy,
but does not establish that the LLM can derive continuation value from a predictive
belief representation.

This ablation removes every expected-entropy, information-gain, rank, and preferred
action field. For each legal continuation it supplies only:

- the possible observation labels;
- each observation's calibrated probability under the current branch posterior; and
- the edible/poisonous posterior after that observation.

The model must aggregate uncertainty over those outcomes and return one legal menu
index per branch. Machine-fixed roots, legal menus, histories, exact verifier, model,
temperature, and response grammar remain unchanged. Projection is disabled.

## S0 viability smoke

- Fresh seed `24176`.
- Ten distinct posterior cells generated by the existing frozen smoke constructor,
  spanning uncollected and collected states and histories of length zero through four.
- `openai/gpt-5.4-mini` through OpenRouter, non-thinking, temperature zero,
  128-token output cap, with one bounded correction response for invalid JSON only.
- Branch quality is measured over every positive-probability branch of all four fixed
  roots. A choice is exact-optimal when its expected class entropy is within the
  environment `EPSILON` of the minimum legal continuation. The uniform-menu reference
  is the mean fraction of exact-optimal indexes in each branch menu.

All requirements must pass:

1. All ten cells complete with legal roots and follow-ups.
2. Collection is represented in every uncollected cell.
3. Exactly ten logical calls, zero projected cells, zero reasoning tokens, zero forced
   exits, and zero scoring-time model calls.
4. At least 50% of branch choices are exact-optimal.
5. Exact-optimal branch frequency exceeds the uniform-menu reference by at least
   20 percentage points.
6. The retained prompts contain predictive outcome evidence but no expected entropy,
   information gain, utility score, action rank, or preferred action.

Any failure stops this line. A pass authorizes a separately frozen proposal-quality
gate; it does not authorize a trajectory confirmation. No alternate seed, prompt
repair, or threshold change follows a failure.
