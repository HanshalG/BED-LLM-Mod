# LLM-Native Second-Environment Audit

Date: 2026-08-05

## Decision

Do not spend the next OpenRouter day reopening Animals, Detective, InfoQuest,
or MovieLens. Run the already-frozen fully fresh Number Game source stage
first. The strongest later second-environment mechanism is Zendo, but it needs
a genuinely new task source or benchmark split rather than another interface
amendment on the ten already-used public rules.

This is a zero-call synthesis of banked results. It opens no endpoint and does
not authorize a paid run.

## Evidence

| Environment | Best evidence | Blocking evidence | Decision |
| --- | --- | --- | --- |
| Animals / 20 Questions | Natural semantic hypotheses and LLM regeneration | Broad prior-matched supports contain truth initially; narrow supports rarely recover it; deeper policies do not replicate | Closed as a new headline route |
| CA-BED Detective | Depth-two score tracks entropy reduction | It ranks truth-posterior gain backwards; exact answers restore calibration but remove most action opportunity | Closed |
| InfoQuest | Released trajectories show large delayed discovery and nonsaturated completion | Shared actions, semantic partitions, cached-answer replay, information-need scoring, and fresh max-resolution confirmation all fail the causal first link | Closed without a new external likelihood or target representation |
| MovieLens | Load-bearing profile dynamics and one explicit ranking gate pass | Depth-two and receding policies lose; response is concentrated in a small user subset | Closed at the tested apparatus |
| Zendo | One blinded task selects a lower-immediate-EIG root and improves realized truth agreement by `0.096605`; regenerated executable particles are load-bearing | Seven-rule confirmation never reaches an endpoint because free-form executable populations fail strict serving; all ten public rules have now received calls | Best second-environment mechanism, but no pristine replication source remains |
| Number Game | Powered dynamic-support gain and disjoint history-blind first-link confirmation both pass | Fully fresh source plus matched history-blind control is still pending | Highest-priority formal run |

## Next Gate

1. Complete the hash-bound fully fresh Number Game source and later-day
   history-blind control under the daily budget protocol.
2. Only after that composite is banked, search for a Zendo-like released task
   family with fresh executable semantic rules and an external truth function.
3. Require a provider-enforced or locally constrained typed grammar to pass a
   content-disjoint serving gate before any multi-rule endpoint is opened.
4. Preserve the scientific comparison from the successful Zendo smoke:
   aligned future regenerated beliefs versus myopic, fixed-support,
   history-blind/root-only, shuffled-future, and random controls.

The key criterion is not merely that support changes. A candidate environment
must jointly provide path-dependent generated support, a truth-anchored external
endpoint, and a calibrated first-link ranking signal.
