# Tau2 MMS Array Semantic Calibration Protocol

Date frozen: 2026-08-13

## Predecessor Boundary

The first Tau2 typed semantic mechanics interface is terminally closed. Its
registered parser rejected provider-reordered object keys, and its non-gating
diagnostic also showed that the mobile family failed semantic calibration.
That run and its seeds are not reopened.

The immutable diagnostic did establish a prospective reason for one new route:
both MMS families had zero source-equivalent leakage, all 16 native permission
signatures were exact, all four depth-two plans selected `installed_apps`, and
MMS-home Brier was 0.0125. This successor tests transport and generalization on
six untouched reserve episodes. Mobile is excluded rather than repaired.

## Fresh Cohort

Select the first three `mms_abroad` and first three `mms_home` episodes in the
already frozen reserve ordering. The six episode hashes are fixed in the public
calibration manifest; task IDs, backbones, target faults, selected tool
responses, repair actions, and task-success endpoints are not serialized.
Every episode contains four candidate worlds.

## Model Interface

The model and scientific role are unchanged: exact
`deepseek/deepseek-v4-flash-0731`, nonreasoning, predicts a complete typed
semantic forward model for all nine MMS reads in every supplied candidate
world. Code supplies semantic world descriptions, legal unlock structure, and
closed observable-field vocabularies, then forms normalized likelihoods,
performs Bayes updates, and computes exact depth-two information values.

The transport is prospectively new. Each world contains an ordered `actions`
array. Every action row contains:

- its exact `action_id`;
- an ordered `fields` array of exact `field_id` and string `value`; and
- confidence in `[0.50, 0.95]`.

Boolean values are literal strings `true` and `false`; enum values use the
supplied closed vocabulary. Code requires exact world, action, and field order,
exact membership, and no extras. Object-key ordering has no scientific role.
The same confidence-to-categorical-likelihood rule and `OTHER` category as the
closed predecessor are retained.

The model sees no selected task ID, source fault ID, raw tool response, hidden
true state, repair action, reward, entropy, EIG, selected policy, or endpoint.
All six raw responses are durably banked before any selected tool response is
loaded.

## Gates

All gates are conjunctive.

1. Exactly six accepted requests/HTTP attempts; zero retries, reasoning,
   forced exits, provider errors, or parser repairs; all likelihood rows finite
   and normalized.
2. Exactly 216 world-action cells. Typed-signature accuracy is at least `0.90`,
   overall multiclass Brier is at most `0.18`, and each MMS family Brier is at
   most `0.25`.
3. Across 24 `messaging_permissions` cells, at least 23 signatures are exact,
   at least 23 realized posteriors top-rank the true world, mean true-world
   posterior is at least `0.65`, and mean posterior Brier is at most `0.18`.
4. Across source-equivalent pairs, mean predicted total variation is at most
   `0.03` and maximum at most `0.10`.
5. Semantic greedy avoids `installed_apps` and semantic depth two selects it in
   all six episodes; every horizon gain is at least `0.10` nats and mean gain is
   at least `0.50` nats.
6. Pooled semantic-versus-exact two-step root-value Spearman is at least `0.80`
   over all 48 episode-root cells.
7. Raw-response ordering, source privacy, predecessor terminal binding, daily
   accounting, unopened downstream paths, and independent replay all pass.

Passage is `mms_array_semantic_pass` and authorizes only a separately frozen
paired development protocol. Failure closes this exact interface/cohort/seeds.
It never opens a policy endpoint by itself.
