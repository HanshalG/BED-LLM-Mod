Frozen: 2026-08-08 (Europe/London), before any Bongard mechanics,
development, or confirmation endpoint was opened.

Status: **complete endpoint-sealed plan bank; zero API calls, zero candidate
outcomes, and zero endpoint outcomes**.

This protocol adds a non-LLM learned-vision comparator without changing the
frozen Luna requests, tasks, actions, endpoints, science gates, result mapping,
or budget. It never authorizes a paid call or endpoint opening.

## Why This Control Exists

The registered myopic, fixed-support, history-blind, matched-updater, shuffled,
and random policies isolate planning mechanisms while sharing predictive
particles generated by Luna. They do not answer whether a frozen ordinary
vision representation can supply a competitive likelihood model for this
particular endpoint task.

The new control therefore makes the strongest cheap comparison available:
the same two-query budget and sealed endpoint objective, but a fixed
self-supervised DINOv2 representation with no language model, free-form rule,
or answer-conditioned support generation.

## Fixed Predictive Model

At a history, unit-normalized positive and negative prototypes are the
normalized means of the labelled image embeddings. For image embedding `x`,
the signed score is

```text
s(x) = cosine(x, positive prototype) - cosine(x, negative prototype)
P(positive | x, history) = sigmoid(scale * s(x)).
```

The bias is fixed at zero to preserve class-complement symmetry. The scale is
selected from `{0.25, 0.5, 1, 2, 4, 8, 16, 32, 64}` using only 272
leave-one-out predictions among the four initially observed images in
mechanics plus development. No candidate or endpoint outcome enters selection.
The frozen choice is `scale = 2`, with leave-one-out log loss `0.658221`.

After a simulated or realized query, its embedding is appended to the
corresponding class prototype. This deterministic update is intentionally not
semantic or generative.

## Policies

`dinov2_myopic` selects the candidate with maximum expected reduction in the
sum of marginal entropies of the two sealed endpoint predictions. After the
first outcome, it recomputes the same one-step score for query two.

`dinov2_depth2` selects the first candidate by exact two-step expectimax over
both first labels and the best remaining second query. Query two uses the same
one-step score because one query remains. Signed utilities are retained because
prototype updates can increase endpoint uncertainty.

Ties use the repository's deterministic lexicographic rule. Every first-label
and second-label branch, second action, and final endpoint probability was
precomputed before outcomes. The plan bank SHA-256 is
`58154f052424f1632c302f9b40af030c172fc4d626908c9f977211c1e8299847`;
its manifest SHA-256 is
`56e9d538ded501f4518dc662d8403f3f15ba254c8cedb132e4bd09d10949e504`.

Depth two already changes a robust first action on 1/4 mechanics, 14/64
development, and 34/96 confirmation tasks. This is structural opportunity,
not performance evidence.

## Outcome Interpretation

The frozen interpreter may run only after the corresponding existing Bongard
stage independently opens its outcomes. It follows the precomputed branch for
the realized first label, then the realized second label, and scores the stored
endpoint probabilities. It reports per-task and pooled Brier score, log loss,
accuracy, and truth probability for both policies.

The primary classical horizon contrast is paired
`dinov2_depth2 - dinov2_myopic`; lower is better for Brier/log loss and higher
is better for accuracy/truth probability. Every paired mean receives a fixed
20,000-draw task bootstrap interval using seeds `20260808` onward. No result may
change these metrics, directions, seeds, policies, calibration, or plans.

After any reported Luna Bongard endpoint result, the corresponding DINO values
must also be reported. A Luna-vs-DINO comparison is descriptive unless an
additional comparison was frozen before that stage. If DINO matches or beats
Luna, the paper must say so and may not imply that the task itself requires an
LLM. If Luna's registered path-dependent controls pass while DINO is strong,
the narrower valid claim is about answer-conditioned LLM belief dynamics, not
universal representation superiority.
